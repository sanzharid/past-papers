# Maths Quest

A front-end-only practice game for the Year 6 Pre-Test half-term papers (Practice Papers 1–4, October 2026).

- 192 questions from the four papers, each with a worked solution taken from the teacher's answer sheets.
- **Paper Worlds**: each paper is a world of 10-question stages that unlock in order, with up to 3 stars per stage.
- **Topic Islands**: practise one topic at a time.
- **Quick Blitz**: 10 mixed questions against a 90-second clock.
- **Daily 5**: keeps a daily streak going.
- **Fix Mistakes**: replays questions answered wrongly.
- XP, levels and badges. Progress is saved in the browser only.

No build step: open `index.html`, or serve the folder with GitHub Pages.

Questions that asked for drawing or explaining were turned into multiple choice with the same idea. On Paper 3, Q18c the answer sheet gives a mean of 5 1/3. The marks add up to 54, so the game uses 54 ÷ 9 = 6.
